# shoping-cart# Shopping Cart - Team Project

CSE326 Internet Programming | Section K4P26HB | Group 01

A frontend shopping website (customer store + admin panel). No backend: data is kept in the browser (localStorage).

| Part      | Teammate    | Files                                              |
|-----------|-------------|----------------------------------------------------|
| Structure | Ankith      | all `*.html` and `admin/*.html`                    |
| Styling   | Shreya      | `css/base.css, desktop.css, tablet.css, mobile.css`|
| Logic     | JS teammate | `js/main.js` and `js/<page>.js`                    |

Each person's learning guide is in `docs/` (PDF). See `GIT-GUIDE.md` for how to commit.

## Run
Open `index.html` in Chrome. Demo logins: `admin@shop.com / admin123`, `user@shop.com / user123`.

## Features
- Shop with search, filters, sorting; product page with gallery, reviews, related items
- Wishlist, cart with coupons (SAVE10, WELCOME5), GST and shipping rules, checkout with card validation
- Orders with status tracker; account page; light/dark theme; responsive (desktop, tablet, phone app style)
- Admin: dashboard, product add/edit/delete with images, order status, customers

## Pages
Store: index, product, wishlist, cart, checkout, orders, account, login, register, 404
Admin (admin/): dashboard, products, orders, users
